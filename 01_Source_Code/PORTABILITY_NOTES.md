# Release portability changes

The supplied model mathematics, tensor values, data augmentation, loss definition, threshold selection, and recorded results are unchanged. The release adds an executable relative-path configuration, replaces obsolete workspace defaults, and resolves the current Python interpreter for subprocesses. Optional embedded architecture dictionaries allow trained checkpoints to load offline. Checkpoint metadata is converted from numerical-library scalars to primitive values so `weights_only=True` can load it safely; all state tensors remain byte-identical to the originals. Metric dictionaries now emit equivalent primitive scalars so newly trained checkpoints support the same safe loader. Evaluation additionally accepts a CPU device and a bounded sample count for functional checks.

The local release checks covered all 30 checkpoint loads and finite 256-by-256 forward passes, seven principal command-line interfaces, table recomputation against archived results, and the end-to-end evaluator on two public benchmark pairs for each selected family. Those small functional checks are not added to manuscript accuracy results. The complete benchmark and restricted project application were not rerun during packaging.
